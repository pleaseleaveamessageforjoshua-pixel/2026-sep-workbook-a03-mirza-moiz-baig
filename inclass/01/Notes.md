# Danger of Cloud-Synced Folders

Do NOT store your Git repositories in:

OneDrive

Dropbox

Google Drive

iCloud

These services constantly modify files in the background, which can:

Corrupt your Git history

Break your repo

Cause merge conflicts

Delete or revert files

Always store your repos in a normal folder like:

Code
C:\Users\Joshua\Documents\Code\
JavaScript Documentation
Official documentation is on MDN:
https://developer.mozilla.org/docs/Web/JavaScript
